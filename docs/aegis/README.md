# Cartie Aegis Workspace

This workspace stores design and planning artifacts for non-trivial Cartie changes.

- `baseline/` contains evidence snapshots used before design/planning.
- `specs/` contains approved or review-pending specs.
- `INDEX.md` lists workspace artifacts.
- `BASELINE-GOVERNANCE.md` defines how baseline drift is handled.

These files are design authority only after user review. They do not mutate runtime behavior.
