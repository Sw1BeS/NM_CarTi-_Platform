# CarTié — Change Protocol (P0)

📌 Обязательный протокол для любых изменений
1️⃣ Локализовать точку изменения:
   🔘 “Где вход?” (route/controller/webhook)
   🔘 “Где бизнес-логика?” (service/module)
   🔘 “Где данные?” (Prisma models / entity records)
2️⃣ Изменять только нужное:
   🔘 без массовых перемещений файлов
   🔘 без переименований “для красоты”
3️⃣ Сохранить обратную совместимость:
   🔘 новые поля — optional + дефолты
   🔘 миграции — идемпотентные
4️⃣ Добавить минимальную проверку:
   🔘 unit/vitest если затронута логика
   🔘 или хотя бы health + один end-to-end TG сценарий

📌 Definition of Done (минимум)
1️⃣ Код компилируется.
2️⃣ `api/health` зелёный.
3️⃣ TG webhook принимает апдейты и не падает.
4️⃣ Лид создаётся с корректным именем/username (если доступны из TG).
5️⃣ Нет дублей по очевидным ключам (chatId+messageId / source ids).

📌 Стиль правок
1️⃣ Делаем “малые PR” (1 фича/фикс = 1 ветка).
2️⃣ В описании: “что было”, “что стало”, “как проверить” (3 пункта).
