# MTProto Connector — Rules (P1)

📌 Назначение MTProto в CarTié
1️⃣ Подключать источники (каналы/чаты) без хардкода.
2️⃣ Синхронизировать посты за период.
3️⃣ Маппить в CarListing/Draft/B2B сущности по конфигу ChannelSource.

   🔘 корректное создание сущностей
